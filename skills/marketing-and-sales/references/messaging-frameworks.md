# Messaging Frameworks

## Value Proposition Canvas

For every KodaSōken product, fill this out before writing any copy:

```
PRODUCT: [name]
AUDIENCE: [primary persona]

PAIN (what they suffer now):
- [Concrete pain point 1]
- [Concrete pain point 2]
- [Concrete pain point 3]

GAIN (what they want instead):
- [Desired outcome 1]
- [Desired outcome 2]
- [Desired outcome 3]

OUR SOLUTION (how we bridge pain → gain):
- [What we do, in one sentence]
- [Why only we can do it]
- [Proof it works]

AFTER (what their world looks like with us):
- [Measurable change 1]
- [Measurable change 2]
```

## Message Hierarchy Builder

### 1. One-Liner (5-10 words)
The answer to "what do you do?" at a dinner party.

**Formula:** [What it does] + [for whom] + [key outcome]
**Example:** "Clinical documentation that writes itself — for Japanese doctors."

**Test:** Can someone repeat it after hearing it once?

### 2. Elevator Pitch (30-60 seconds spoken / 3-4 sentences)
The answer to "tell me more."

**Structure:**
1. The problem (1 sentence, specific and relatable)
2. Our solution (1 sentence, concrete)
3. Why it's different (1 sentence, defensible)
4. The result (1 sentence, quantified if possible)

**Example:**
"Japanese doctors spend 2-4 hours daily on clinical documentation after seeing patients. KODA KENKŌ's documentation AI reduces that to 30 minutes — it listens, understands medical Japanese, and writes structured notes directly into the hospital EMR. Unlike generic AI tools, it's built for Japanese clinical workflows and complies with MHLW data residency requirements. Hospitals using it report 60% reduction in overtime documentation, with full rollout in 4 weeks."

### 3. Executive Summary (3-5 paragraphs)
For website product pages, investor decks, press releases.

**Structure:**
- Paragraph 1: Problem + market context
- Paragraph 2: Solution + differentiation
- Paragraph 3: Traction + proof
- Paragraph 4: Vision + call to action

### 4. Full Narrative
For pitch decks, white papers, investor memos.

Use the asset templates: `assets/pitch-deck-outline.md`, `assets/one-pager-template.md`.

## Positioning Statement Template

```
For [PRIMARY AUDIENCE]
who [SPECIFIC NEED OR PAIN],
[PRODUCT NAME] is a [CATEGORY]
that [KEY BENEFIT].
Unlike [COMPETITION OR STATUS QUO],
we [UNIQUE DIFFERENTIATOR].
```

**Example:**
"For Japanese hospital administrators who face documentation backlog and MHLW compliance pressure, KODA KENKŌ Clinical is an AI-powered documentation layer that reduces physician overtime by 60% while ensuring full compliance. Unlike generic AI scribes built for English, we understand Japanese clinical language natively and deploy on-premises within existing EMR workflows."

## Category Design

When positioning a product, the category is as important as the product. Choose carefully:

### Bad Categories (overcrowded, meaningless)
- "Healthcare AI platform"
- "Digital health solution"
- "Medical software"

### Good Categories (specific, ownable)
- "AI-powered clinical documentation layer for Japanese hospitals"
- "Linux-native medical AI operating system"
- "Real-time medical Japanese NLP engine"

### Category Design Rules
1. Be specific enough to be the only one in the category
2. Be broad enough to grow into
3. Make the problem obvious from the category name
4. Avoid "platform" unless you're actually a platform (ecosystem, not product)

## Simplicity Filter

After writing any marketing copy, run it through all four:

1. **Tired doctor test:** Would an exhausted physician at 11pm understand this in one read?
2. **Boss relay test:** Could a stressed admin repeat this to their department head from memory?
3. **Investor retention test:** Would an investor scanning 20 decks remember this one?
4. **Family member test:** Would a patient's worried relative feel reassured or confused?

If any fail, rewrite. If all pass, ship.
