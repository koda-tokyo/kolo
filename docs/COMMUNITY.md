# Community

| Need                                         | Where                                                                                               | Notes                                                                             |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Help with install, config, operation         | [GitHub Discussions, Q&A](https://github.com/koda-tokyo/kolo/discussions/categories/q-a)            | Use the form; include version and OS                                              |
| A defect                                     | [Issues, bug form](https://github.com/koda-tokyo/kolo/issues/new?template=bug.yml)                  | Run `kolo doctor` first; redact secrets                                           |
| A capability you want                        | [Issues, feature form](https://github.com/koda-tokyo/kolo/issues/new?template=feature.yml)          | Check [ROADMAP.md](https://github.com/koda-tokyo/kolo/blob/main/ROADMAP.md) first |
| An idea to discuss before code               | [GitHub Discussions, Ideas](https://github.com/koda-tokyo/kolo/discussions/categories/ideas)        | Required for anything larger than a small addition                                |
| A vulnerability                              | security@kodasoken.com, see [SECURITY.md](https://github.com/koda-tokyo/kolo/blob/main/SECURITY.md) | Never a public issue                                                              |
| A hardening proposal that is safe to discuss | [Issues, security form](https://github.com/koda-tokyo/kolo/issues/new?template=security.yml)        | Non-exploitable only                                                              |
| Commercial support, evaluation licence       | support@kodasoken.com                                                                               | See `docs/EVALUATION_LICENSE.md`                                                  |

## Contributing

Read [CONTRIBUTING.md](https://github.com/koda-tokyo/kolo/blob/main/CONTRIBUTING.md), [GOVERNANCE.md](https://github.com/koda-tokyo/kolo/blob/main/GOVERNANCE.md) and [LICENSING.md](https://github.com/koda-tokyo/kolo/blob/main/LICENSING.md). Pull requests are accepted for the MIT and FSL layers; each commit is signed off under the CLA. The pull request template lists the checks reviewers apply.

## Release cadence

Releases are cut from `main` by maintainers. Each release has notes in `CHANGELOG.md` following the template in `.github/release-notes-template.md`: upgrade notes, added, changed, fixed, security, documentation, verification. Security fixes go to the latest stable and the latest beta.

## Conduct

The project follows its [Code of Conduct](https://github.com/koda-tokyo/kolo/blob/main/CODE_OF_CONDUCT.md).
